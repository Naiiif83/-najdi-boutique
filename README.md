# بسطة الوالدة — متجر فساتين شعبية وقمصان الروز

متجر إلكتروني كامل (سلة + دفع أونلاين) بطابع نجدي/شعبي، مبني بالكامل على منصة
Cloudflare (Pages + Functions + D1 + R2) بدون تكاليف استضافة شهرية.

**المميزات:**
- عرض المنتج بتقنية **دوران 360°** بالسحب (يعتمد على صور حقيقية للمنتج من عدة زوايا).
- سلة تسوّق، صفحة دفع، ودفع إلكتروني عبر **Moyasar** (مدى، فيزا/ماستركارد، Apple Pay، STC Pay).
- **لوحة تحكم** بسيطة لإضافة/تعديل/حذف المنتجات ورفع الصور بدون أي برمجة.
- تصنيفات جاهزة: فساتين الأطفال، فساتين الشابات، فساتين كبار السن، قمصان الروز.

---

## 1) التجهيزات قبل النشر

تحتاجين:
1. حساب [Cloudflare](https://dash.cloudflare.com) (مجاني).
2. حساب [Moyasar](https://moyasar.com) لتفعيل الدفع الإلكتروني (اختياري بالبداية — الموقع يشتغل بدونه، بس زر الدفع ما يظهر).
3. تثبيت أدوات النشر على جهازك:
   ```bash
   npm install
   npx wrangler login
   ```

## 2) إنشاء قاعدة البيانات والتخزين (مرة واحدة فقط)

```bash
# إنشاء قاعدة بيانات المنتجات والطلبات
npx wrangler d1 create najdi-boutique-db
```
انسخي `database_id` اللي يطلع لك وحطيه مكان `REPLACE_WITH_YOUR_D1_DATABASE_ID` في ملف `wrangler.toml`.

```bash
# تجهيز الجداول
npm run db:migrate:remote

# إنشاء مكان تخزين الصور
npx wrangler r2 bucket create najdi-boutique-images
```

## 3) رفع المشروع على GitHub وربطه بـ Cloudflare Pages

الأسهل: من لوحة Cloudflare Dashboard →
**Workers & Pages → Create → Pages → Connect to Git** → اختاري هذا المستودع.
اتركي إعدادات البناء فاضية (لا يوجد Build command، ومجلد الإخراج هو `public`).

بعد أول نشر، اربطي القاعدة والتخزين من إعدادات المشروع:
**Settings → Functions**:
- **D1 database bindings**: أضيفي `DB` → `najdi-boutique-db`
- **R2 bucket bindings**: أضيفي `IMAGES` → `najdi-boutique-images`

## 4) إعداد المتغيرات السرية

من **Settings → Environment variables** (اختاري Encrypt للسريّة) أضيفي:

| المتغير | القيمة |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور قوية لدخول لوحة التحكم |
| `ADMIN_SESSION_SECRET` | نص عشوائي طويل (30+ حرف) لتوقيع الجلسة |
| `MOYASAR_SECRET_KEY` | المفتاح السري من حساب Moyasar |

ومن **Settings → Variables** (عادية غير سرية):

| المتغير | القيمة |
|---|---|
| `STORE_NAME` | اسم متجرك، مثلاً "بسطة الوالدة" |
| `MOYASAR_PUBLISHABLE_KEY` | المفتاح العلني من حساب Moyasar |

بعد إضافة أي متغير، اعملي **Retry deployment** حتى يتفعّل.

## 5) الدخول للوحة التحكم

افتحي `https://your-project.pages.dev/admin/login.html` وسجّلي دخول بكلمة
المرور اللي حطيتيها (`ADMIN_PASSWORD`). من هناك تقدرين تضيفين منتجات وترفعين
صورهم مباشرة.

## 6) تصوير المنتجات لعرض 360°

لأفضل نتيجة:
- ثبّتي الجوال على حامل (تريبود) وحطي المنتج على منصة دوّارة أو دوّريه يدوياً بزوايا متساوية.
- التقطي من **12 إلى 24 صورة** لدورة كاملة (كل 15–30 درجة صورة).
- ارفعيها في لوحة التحكم بنفس ترتيب التصوير — الموقع يرتبها كما رفعتيها.
- لو المنتج ما له صور دوران كافية (أقل من 3 صور)، الموقع تلقائياً يعرضها كمعرض صور عادي بدل خاصية السحب.

## 7) ربط دومين خاص (اختياري)

من **Custom domains** في إعدادات مشروع Pages أضيفي دومينك الخاص إذا توفر
لاحقاً، ولحين ذلك الموقع شغّال على رابط `xxx.pages.dev` المجاني.

## 8) التطوير محلياً (اختياري)

```bash
npm run dev
```
